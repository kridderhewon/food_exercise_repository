폰 바탕화면 앱 설치 & 데이터 관리

제미나이 화면이 아닌 '진짜 내 전용 앱'으로 바탕화면에 까는 법

제미나이 안에서 링크를 공유하면 제미나이 채팅창이 공유됩니다. 아래 버튼을 눌러 완전체 앱 파일(index.html)을 다운로드한 뒤 무료 사이트에 올리면 상단 링크(주소창) 없이 바탕화면에서 바로 열리는 나만의 안드로이드 앱이 됩니다!

💡 10초 만에 내 폰 바탕화면 전용 앱 만들기:

1. 위 버튼을 눌러 index.html 파일을 다운로드합니다.

2. 무료 호스팅 사이트인 app.netlify.com/drop 또는 tiiny.host 에 접속해 방금 받은 파일을 끌어다 놓으면 나만의 전용 주소(https://...)가 즉시 생성됩니다.

3. 안드로이드 크롬/삼성인터넷으로 그 주소에 접속한 뒤 메뉴(⋮) → [홈 화면에 추가 / 앱 설치]를 누르면 상단 인터넷 주소창이 아예 안 보이는 순정 앱으로 바탕화면에 설치됩니다!

외부 설치용 Gemini API 키 설정 (선택사항)

이곳 미리보기에서는 키 없이도 AI 사진 분석이 바로 작동합니다. 만약 파일을 다운로드해 개인 주소로 설치하셨다면 Google AI Studio(aistudio.google.com)에서 무료 발급받은 API 키를 입력해 주세요.
